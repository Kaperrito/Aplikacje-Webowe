git init - tworzy nowe repozytorium w obecnym folderze
git status - pokazuje zmiany oraz czekające w poczekalni
git add plik.txt - dodaje nowy plik do poczekalni
git add . - dodaje wszystkie pliki z obecnego folderu 
git commit -m "opis zmiany" - zapis z wymaganym opisem
git diff - zmiany względem poprzedniej wersji
